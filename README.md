# NanoMatAI — предсказание band gap 2D-полупроводников по структуре

Инструмент машинного обучения для наноэлектроники: по кристаллической структуре
2D-материала за секунды предсказывает ширину запрещённой зоны (band gap), тип щели
и честную оценку неопределённости — там, где DFT-расчёт занял бы часы.

---

## Что он делает

Вход: структура монослоя (CIF / POSCAR / .vasp).
Выход:
- **Band gap (PBE)** — ширина щели, MAE ≈ **0.23 эВ** на тесте;
- **Оценка экспериментальной щели** — с калиброванной поправкой PBE→эксперимент;
- **Тип щели** (прямая / непрямая) — ROC-AUC ≈ **0.80**;
- **Неопределённость** — разброс ансамбля из 5 моделей, с вердиктом «надёжно / проверить /
  вне области применимости».

Два режима: интерактивная веб-морда (`--app`) и батч-скрининг списка кандидатов
(`--in папка --out results.csv`, результат ранжирован по щели).

---

## Как это сделано (коротко)

- **Модель:** CGCNN (кристаллическая графовая нейросеть, PyTorch Geometric). Атомы — узлы,
  связи в радиусе 8 Å — рёбра, признаки рёбер — расстояния через RBF.
- **Данные:** 13 349 стабильных 2D-полупроводников из Alexandria (PBE, `e_above_hull ≤ 0.1`).
  Всё через открытые API (JARVIS), без собственного парсера.
- **Ключевой результат проекта:** структура бьёт состав только при достатке данных.
  Composition-baseline (Magpie + RF/XGBoost) и CGCNN шли вровень на 700 структурах,
  но с ростом до 13k структурная модель оторвалась (MAE 0.58 → 0.21).
- **Надёжность:** ансамбль для калиброванной неопределённости; transfer learning с 3D
  (dft_3d, 76k) даёт небольшой прирост.

| Этап | N | MAE (эВ) |
|---|---|---|
| Состав (baseline) | 13 349 | 0.36 |
| Структура (CGCNN) | 13 349 | **0.21** |

## Внешняя валидация на эксперименте

7 каноничных монослоёв, модель vs измеренные оптические щели:

| Материал | Модель (PBE) | Эксперимент | unc |
|---|---|---|---|
| MoS₂ | 1.67 | 1.88 | ±0.06 |
| WS₂ | 1.87 | 2.00 | ±0.04 |
| WSe₂ | 1.50 | 1.65 | ±0.12 |
| MoSe₂ | 1.50 | 1.55 | ±0.10 |
| h-BN | 4.81 | 6.00 | ±0.27 |

- PBE систематически занижает на ~0.42 эВ (~15%); линейная поправка снижает MAE 0.42→0.22.
- Для TMD модель близка к оптической щели (экситонное связывание в 2D частично гасит
  занижение PBE); для широкозонного h-BN занижение максимально — поведение физически
  ожидаемое.

---

## Границы применимости (честно)

- Обучена **только на полупроводниках** → на металлах/полуметаллах (графен) даёт
  бессмыслицу. **Но** неопределённость это ловит: у таких случаев unc втрое выше → вердикт
  «вне области применимости». Доверять предсказанию стоит при `verdict = надёжно`.
- Таргет — **PBE-щель**; истинная (эксперимент) выше, для этого встроена поправка.
- Слабее на лёгких main-group соединениях (бориды/нитриды/оксиды) — их в обучении меньше,
  чем TMD. Ошибка определяется плотностью данных в данной химии, не «сложностью физики».

## Запуск

```bash
# веб-морда
python screen_bandgap.py --app

# батч-скрининг папки кандидатов -> ранжированный CSV
python screen_bandgap.py --in structures/ --out results.csv
```
Нужны веса (с обучения на Kaggle): `cgcnn_2d_ensemble.pt` (+ опц. `cgcnn_2d_typed.pt`).
Инференс на CPU. Зависимости: torch, torch_geometric, pymatgen, gradio.

## Вопросы к лаборатории (точка входа в разговор)

1. Какое свойство 2D-материалов вам реально нужно предсказывать быстро — band gap, тип
   щели, эффективная масса, работа выхода, стабильность?
2. На каком классе материалов вы работаете (TMD, MXene, main-group)? Туда ли смотрит
   модель, или нужен добор данных под вашу химию?
3. Что важнее — точность величины щели или надёжный фильтр «этому предсказанию не доверяй»
   (скрининг больших списков кандидатов)?
4. Есть ли у вас экспериментальные данные, на которых можно дообучить/проверить модель?
